## 🚀 How to Execute the Lab Experiments

### 1. In a Web Browser (Google Chrome / Microsoft Edge):
1. Navigate to any lab directory (e.g., `Lab1/`).
2. Double-click or open `index.html` in your web browser.
3. Press <kbd>F12</kbd> (or <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>I</kbd>) to open **Developer Tools**.
4. Select the **Console** tab to view the live script outputs and test interactive elements.

### 2. In Node.js (Command Line / Terminal):
All labs (Labs 1–8 and 10–15) are directly executable in Node.js:
```bash
# Example for Lab 1
cd JavaScript-Practicals/Lab1
node script.js

# Example for Lab 15
cd ../Lab15
node script.js
```
*(Note: Lab 9 includes browser-native DOM APIs, `localStorage`, and HTML event listeners, and is designed to run in a web browser).*
